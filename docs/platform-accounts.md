## 2. 预注册执行建议

按"一次人工投入换最多单"的顺序做：

1. **Moka**（邮箱码全局通用）：邮箱验证码一次注册，登录态全网复用 → 收益最大、成本最低。
2. **智联**（全站通用）：手机码/扫码一次；顺手把账号级在线简历填好，网申表自动带出。
3. **飞书**：无邮箱口，手机码注册；sms-code 自取打通后基本免人工。
4. **北森**（数量最多，但租户独立）：**预注册收益低**——每个企业站都要单独扫一次码。建议只在第一个北森单把"扫码→绑邮箱"流程跑熟，绑好邮箱后续绑码环节可 himalaya 自取（发码前 GeeTest 仍要人/特种兵）。
5. **hotjob**（仅扫码）：同样租户级，无法提前批量预注册；保持微信扫码通道（§8.6）畅通即可。
6. **国聘 / 51job / 猎聘 / 牛客 / BOSS**：入口少、方式待实测；批量开始前各试一家补齐本表。
7. **自建门户**：无法预注册，靠 L3 短信码自取 + 图形码交用户兜底；已经注册过的先查实例 accounts.md。

## 3. 登录态保持方法（ego lite 默认 profile）

- 所有平台用 ego lite **默认 profile** 登录，cookie/会话落在 profile 里，worker 的 TaskSpace 复用同一 profile 即带登录态。
- 同一门户账号不要多个空间并发登录（sop §5）。
- 登录态是否还在：worker 开门户看右上角头像/账号即可判断，掉了按 §1 的"登录态保持"列恢复。
- 手机号换绑（智联等需要旧号验证）是用户操作，发现即 handoff 并报主持人，不要等撞墙才处理。
