# 江苏银行（hr.jsbchina.cn，泛微 SPA）

整理自该门户的实际使用（2026 年秋招季）。母行与子公司岗位在同一门户。

## 识别方式

- 域名 `hr.jsbchina.cn`，泛微 e-cology 系 SPA
- 岗位表是 ant-table，岗位名在 `td` 内的 `<a>`，点击新页签打开 `socialDetali?gwid=...`
- 表单 label 带 class `wea-form-item-label`

## 注册登录

- 登录弹窗：账号 / 短信 / 注册；注册需要短信验证码 → handoff

## 投递流程

个人中心 11 个分区逐节填并保存（个人基本信息、目前概况、求职意向、教育经历、能力信息、实习经历、工作经历、家庭成员、奖惩信息、技能标签、其他事项）→ 简历预览回读 → 岗位详情 **“投递简历”**

- **“投递简历”按钮点击即最终提交，没有确认弹窗**，按钮随即变“已投递”。user 档的单不要点
- 求职意向里的期望地点多选时，岗位所在城市建议放第一项

## 必填坑

- **label 与表格表头重名**（如“入学时间”）：必须按 `wea-form-item-label` 过滤，否则日期写进别的框
- **分区导航丢数据**：切换分区时未保存的单选会丢，维护者的“其他事项”9 项声明第一次就没落库，重填后保存才成功
- 日期控件 antd3 calendar，输入框只读：点“YYYY年”头进年代格，选年后停留在同月；点“M月”头进月份格；日期格 `.ant-calendar-date`，注意排除上月/下月格
- 城市 picker 是级联懒加载面板：箭头按钮打开，先滚省份容器再点省 → 市 → 区县
- **搜索类输入（院校、专业）逐字键入会首字错位**（组件异步回填抢光标）：用原生 setter + input 事件注入再点建议项；行内放大镜可以打开全量目录弹窗搜索
- 侧栏导航是 hash 路由 `<a href=#/...>`，元素在视口外时坐标点击会误中头部链接，直接 `a.click()` 或改 hash
- 必填项多：健康、身高体重、自有房、集体户口、毕业时间、籍贯/生源地/户口到县、现居与通讯详细地址、入党时间、目前概况、银行从业经历、期望年薪、笔试地点、服从分配、到岗时间、岗位类型、应聘理由、高中教育经历、家庭成员、奖励与惩罚、技能标签、档案存放单位、获知渠道
- 其它外语证书选项可能只有国内证书，没有雅思托福位

## 附件限制

- 个人基本信息里上传照片，维护者用压缩副本通过

## 提交后核验

- 点击“投递简历”后提示“简历投递成功！”，按钮变“已投递”
- 个人中心 → 投递记录：岗位、单位、城市、日期、“投递成功”
