# 智联校招（含 SCRD 企业定制站）

整理自该门户的实际使用（2026 年秋招季）。

## 识别方式

- 企业站 `<企业>.zhaopin.com`、`<企业><年份>.zhaopin.com`，“立即投递”跳 `xiaoyuan.zhaopin.com`
- 岗位 `xiaoyuan.zhaopin.com/job/<编号>`
- 网申表单 `xiaoyuan.zhaopin.com/scrd/resume2?...`（SCRD 分段简历），志愿页 `/scrd/postprocess2`，成功页 `/scrd/evaluation` 或 `completed2`，投递记录 `/scrd/delivery/record`
- 登录 `passport.zhaopin.com`

## 注册登录

- 微信扫码或手机验证码 → handoff
- **账号是全站通用的**：一处登录，其他智联定制站免登录
- 账号级在线简历在 `i.zhaopin.com/resume`，网申表会预填账号里的旧数据（包括旧手机号），逐项核对
- 登录绑定手机改绑需要旧号验证，只能用户操作；表单里的“个人手机”字段可以单独改成当前号

## 投递流程

岗位页“立即投递” → 志愿选择（第 1 志愿自动带出，“已知晓”倒计时 → 确认志愿弹窗）→ “下一步” → SCRD 分段表单（个人信息 / 教育 / 求职意向 / 家庭 / 实习 / 项目 / 语言 / 奖励 / 承诺 / 附件 / 声明）→ 各段保存 → 侧栏必填段全部打勾 → 预览 → **“立即投递”**

## 必填坑

- **保存是假动作**：出现过点“保存”没有发请求，刷新后全是旧值。每段保存后刷新回读；看网络请求 `POST /api/scrd/resume/update` 返回 200
- **按钮文本带空格**：“保 存”“添 加”。语言段的保存键实际叫“添 加”，按错会被校验拦回而不落库
- **同一时段只允许一条经历在编辑**
- **提交后冻结**：网申表提交后不可编辑；“修改简历”跳账号级简历，那里没有体重、婚姻、通信地址等网申字段
- **选“国外高校”触发留学生必填**：留服认证、外国国籍/居留权、海外工作经历、留学国家、学制、**境外停留天数、境外学习天数**。天数要真实值，无数据 blocked
- **本科选“国内高校”** 触发“是否有国外港澳台学习经历”
- **大学英语四级成绩** 可能为必填，没考要问用户，不能填 0
- 高中教育经历可能为必填（名称、所在地、起止）
- 实习“岗位”字段 maxlength=10，超长要缩写
- 惩处段没有“无处罚”开关：空卡事由填“无”保存
- el-select 重复点击会收起，先判断下拉是否已开
- el-date-picker 只读，打开面板点 `td.available`
- 受教育类型选项是合并文本（如“全日制统分统招”），搜“全日制”搜不到
- 家庭关系节可能只允许单条记录
- 行政区控件有的只到市级，有的到区级
- 生活照、个人信息使用声明（本人意见=同意）也可能是必填

## 附件限制

- 简历附件位可能只支持单附件，账号里的旧附件会带进来；**替换后必须刷新回读**，维护者这里踩过“两次上传界面显示新文件名、实际仍是旧文件”的坑
- 找不到文件选择器时，对隐藏的 `input[name=multipartFile]` 直接上传
- 证件照、生活照在编辑态才出现 input

## 提交后核验

- 成功页“恭喜你已成功投递该企业！”，三步全绿，给出专属校招编码（记在实例留痕）
- **成功页常提示测评**：如“24 小时内完成”，邮件里可能写 72 小时，按短的执行，立即登记 `assessments.md` 并发 assessment 通知
- 投递记录 `/scrd/delivery/record` → “已完成网申”页签
