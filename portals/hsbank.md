# 徽商银行（rczp.hsbank.com.cn）

整理自该门户的实际使用（2026 年秋招季）。

## 识别方式

- 域名 `rczp.hsbank.com.cn/pc/#/...`，自研门户（非北森/Moka/飞书）
- 公告详情 `#/InternshipDetails?id=...`

## 注册登录

- 公告详情点“申请岗位”先弹“请您先登录再进行简历申请” → “去登陆” → 登录弹窗：用户名 + 密码 + 图片验证码
- 登录弹窗内“马上注册”原地展开注册表单（无路由跳转）
- 注册字段：用户名、姓名、邮箱、证件类型、证件号、密码、确认密码、手机号、**手机验证码**、**图片验证码** → 预填后 handoff

## 投递流程

个人中心“我的申请”确认为空 → 个人简历逐段填并逐段保存（个人信息、教育、外语、奖励、亲属、实习、附加）→ 点“本人确认” → “保存个人简历” → 回公告页填志愿：第一志愿、第二志愿、渠道、是否调剂及调剂机构 → **“申请岗位”**

- “保存个人简历”只保存简历，不建申请
- 重复点“申请岗位”会返回“申请失败，您已申请过此职位”，可以作为已投递的证据

## 必填坑

- **本人确认标记会被复位**：任何一段重新保存后都要重新点“本人确认”（class 由 `cancelBg` 变 `sureBg`），再“保存个人简历”
- 教育条目容器用“删除”按钮锚定定位
- 下拉用脚本 `li.click()`
- **专业是三段**：门类 + 词典 + 手填框。词典没有精确专业时按问题库映射规则选近似项，再在第三框手填真实专业名；重选词典项会清空手填框，要补填
- 校验提示“第 N 段”按页面展示顺序计数
- 奖励描述限 20 字
- 渠道选项没有“官网”时选“其他”
- 调剂机构用户可能会自己改，提交后以“我的申请”回读为准

## 附件限制

- 证件照实测压到约 115KB 通过；生活照同时上传

## 提交后核验

- 个人中心 → 我的申请：第一志愿、第二志愿、调剂、招聘类型、投递时间
