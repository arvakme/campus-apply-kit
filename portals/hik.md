# 海康系校招门户

整理自该门户的实际使用（2026 年秋招季）。海康威视及其子公司岗位走同一门户，岗位按“合并类”挂在不同意向下。

## 识别方式

- 域名 `campushr.hikvision.com`
- 岗位列表 `/school?schoolType=...`，岗位详情 `/JobDetails.html?id=...&type=...&batchId=...`
- 我的简历 `/view/mine/resume/index.html`，我的投递 `/myDelivery`
- jQuery 老式页面，校验逻辑在 `/view/mine/resume/index.js` 和 `checkItem.js`

## 注册登录

- 门户账号，邮箱注册，可由用户一次性注册后长期使用
- 点“投递职位”弹登录框

## 投递流程

1. 岗位详情 URL **必须用 `type=2`**（合并类岗位）。`type=0` 打开时 JD 为空、按钮禁用（title“该岗位无投递意向”）
2. “+ 请选择” → 意向弹窗 → 第一意向选具体公司 → 确定
3. 我的简历：勾“我已阅读并同意”解锁 → 个人信息 / 教育经历 / 其他信息 / 原始简历 四个必填区逐区编辑保存
4. 回岗位详情，**重新选意向**（意向不跨登录和刷新保留）→ “投递职位”（滚动到可见，页面上有隐藏占位和可见两个同名按钮）
5. 投递弹窗：勾“我已仔细阅读”，志愿顺序选第一志愿 → **“投递”**（`#JD-send`）

## 必填坑

- **性别 radio 没勾时保存静默失败**：该字段校验不走常规提示，没有红框没有提示，只是不发保存请求
- **同一时刻只允许一个区块在编辑态**，其它区“编辑”按钮带 `unedit` class 点不动
- **导入简历会把各区切回展示态并清掉部分手填值**，导入后逐区点“编辑”补
- 手工填教育经历字段多，建议用“导入简历”（隐藏 input `#addResume` 直接上传）
- `trigger('click')` 会翻转 checkbox 已设值，先判断再点
- 毕业时间是 laydate 只读控件，初值可能被填成当天
- 投递弹窗里“是否能满足实习”类 radio 只对实习岗显示
- 必填字段清单（读 checkItem.js 得到）：
  - 个人信息：姓名、性别、手机、国籍、证件类型、政治面貌、英语等级、毕业时间、意向工作地类型、姓名拼音、出生日期、邮箱、证件号、期望年薪、民族、英语成绩、信息来源、邮寄省/市/区、邮寄地址；国籍为中国时另要籍贯
  - 每条教育经历：起止、学历、学习形式、学制、院系、专业排名、实验室、学号、学校、所在国家、专业、研究方向；有硕士必须同时有本科或专科
  - 其他信息：重大疾病、违法犯罪、持股、亲属在本公司、亲属在同行业、处罚记录，6 项必填是/否
- 下拉值多为编码（如信息来源、学习形式），按选项文本匹配后赋值

## 附件限制

- **证件照上限 500KB**。实测压到约 20KB、498×640 通过
- 照片 input `#addAvact` 不在个人信息表单容器内；上传后提示“上传成功，保存生效”，**必须再点个人信息保存**才落库
- 原始简历区：导入简历时服务端落库，刷新简历页回显文件名即为持久

## 提交后核验

- 岗位按钮变为 title“该职位已投递”并禁用
- 我的投递 `/myDelivery`：岗位、第一志愿/第一意向公司、最新状态“简历投递”
