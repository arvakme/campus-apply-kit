# 门户 playbook

每篇写一个 ATS 或一个自建门户，内容是门户本身的行为，不含任何投递记录。门户会改版，遇到不一致以现场为准，并把新发现补回对应文件。

## 2. 每篇的结构

```markdown
# <门户名>
## 识别方式        URL 特征、页面特征、同厂商不同租户
## 注册登录        入口、需要用户的环节、账号是否跨站复用
## 投递流程        从岗位页到最终提交的页面顺序
## 必填坑          控件怪癖、隐藏必填、静默失败
## 附件限制        简历/照片/附加材料的格式和大小
## 提交后核验      去哪看投递记录、成功页特征、测评提示
```

新增门户按这个结构写。不要写账号、手机号、candidateId、具体姓名和学校。

## 3. 跨门户通用技巧

控件层面（与浏览器工具无关，描述的是现象和解法）：

| 现象 | 解法 |
|---|---|
| 程序赋值后界面显示了，保存时仍报必填 | 框架不认合成事件。改为真实鼠标点击聚焦 + 键盘逐字输入；长文本先全选删除再输入 |
| 下拉点了没反应 / 选项点不中 | 点可见的 select 容器本体；遮罩拦截时用坐标点击或派发 mousedown → mouseup → click；选项在弹层里，按可见元素文本点 |
| 下拉 `input.value` 为空，但界面有值 | 真实值在选中项的文本节点里（antd 读 `.ant-select-selection-item`，飞书读 `...selectItem`） |
| radio/checkbox 的 `checked` 与视觉不一致 | 看组件的 checked class；点左侧勾选框本体而不是文字；`trigger('click')` 会翻转已设值，先判断再点 |
| 日期控件只读 | 打开面板：点年份标题进年视图 → 选年 → 选月 → 选日；年代跨度大时连续翻页 |
| 城市/专业是级联 | 必须选到叶子节点；懒加载要先展开上一级；只选到省会报“请选择XX市” |
| label 找控件找错 | 表格布局下向上找父节点会跨到相邻字段。按 DOM 顺序取 label 之后第一个可见控件 |
| 点“获取验证码”没反应 | 多半是图形验证码遮罩已经弹出，截图确认后 handoff |
| 按钮被浮层拦截 | 先按 Escape 或点空白关弹层；仍拦截则滚动到可见后坐标点击 |
| 截图偶发白屏 | 滚动中截图，等待后重截 |
| 元素引用点击后失效 | 每次操作后重新获取页面快照再取引用 |
| alert 弹窗风暴卡死页面 | 执行脚本前覆盖 `window.alert`；已卡死就开新页，登录态一般保留 |

流程层面：

- **简历解析必然出错**：项目名丢前缀、两段描述并到一条、日期错位、证件号填成手机号、技能区塞几十行垃圾。解析后逐字段对照简历原文。
- **即时回显不可信**：附件、照片、文本都出现过“界面显示已改，服务端没存”。刷新后回读才算数。
- **暂存再刷新**：有暂存按钮的表单，刷新前不暂存会丢数据。
- **同一时刻一个编辑区**：分区编辑的表单，其它区“编辑”按钮点不动，提交前确认没有区块停在编辑态。
- **志愿、意向不跨刷新保留**：投递弹窗里的志愿和意向城市，刷新或关弹窗后常需重选。
- **投递限额**：门户常写“最多投 N 个岗位”“一个月内限投 1 个”，选岗前先看，写进留痕。
- **门户截止日可能早于看板**：以门户为准。

## 用户接管与交还（所有门户通用）

- 需要用户动手（扫码、验证码、登录、终审）：`await task.handOff()` 交出空间，提示用户在 ego 底部控制条点 **Return to agent**
- 用户交还后：`const task = await takeOverTaskSpace(<空间 id>)` 重新接管，再 `task.userPage()` 拿回用户那一页继续；不要用 `taskSpace("名字")` 或旧 task 对象（会报"控制权失败"）
- 报"用户已接管/控制权失败"时最多重试 2 次，然后停手等待或写 blocked，**不许循环重试**
