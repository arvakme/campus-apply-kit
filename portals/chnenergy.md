# 国家能源集团招聘门户（zhaopin.chnenergy.com.cn）

整理自该门户的实际使用（2026 年秋招季）。强制电子附件，缺件无法提交。

## 识别方式

- 域名 `zhaopin.chnenergy.com.cn`
- 渠道由 JS 函数 `recTypeSerch(kinds, schType)` 跳转，URL 形如 `/recTypeSerch?kinds=1&schType=N`：
  - 校园招聘 `kinds=1`：直招 `schType=1`、统招 `2`、菁英管培生 `18`、藏青疆专招 `19`、乡村振兴专招 `7`
  - 社会招聘 `kinds=3`，内部招聘 `kinds=2`
- 岗位详情 `/annc/showgw?id=...`
- 简历分区是独立页面：个人信息 `/resume/editBase`、教育 `/resume/eduList`、资格证 `/resume/qualiList`、工作经历 `/resume/workList`、家庭成员 `/resume/familyList`、成果 `/resume/eidtAchiev`、奖惩 `/resume/eidtReward`、爱好 `/resume/eidtHobby`、自评 `/resume/eidtSelfEvaluate`、电子附件 `/resume/certList`、首选考试城市 `/resume/editFacePlace`

## 注册登录

- 登录：证件号 + 密码 + **手机动态码** + **字符图形验证码** → handoff
- 注册字段：姓名、证件类型、证件号、性别、邮箱、密码（10–30 位，字母开头，需大小写 + 数字 + 特殊字符）、确认密码、验证码、手机号、动态码、协议
- 注册表单是普通 HTML，赋值 + change 事件有效；证件类型 select 的 value 是 `"0"/"1"` 不是文本
- **同门户账号和简历跨公告共用**，简历填一次，多个岗位复用
- 登录态不跨浏览器空间保留

## 查岗

- 下属单位名常与公告里的简称不同（例如公告写“某某院”，门户单位名是“某某技术中心”，法人全称又是另一个名字），先确认法人全称
- 列表页搜索框只搜公告名；直招页搜索框搜岗位名或招聘单位名，**搜不到所属上级单位**，要搜岗位关键词
- 统招页的筛选行（工作单位 + 岗位 + 类型 + 学历）比顶部大搜索框可靠，输入用真实点击 + 键盘
- 同一集团子公司多，搜简称会带出大量同名关联公司，按法人全称精搜
- 门户岗位截止日可能早于看板公告过期日，以门户为准

## 投递流程

岗位页“申请” → 未登录提示 → 登录 → 再“申请” → “您的简历未通过验证，请返回我的简历完善简历信息并验证后，再申请该岗位” → 逐页填简历 → 电子附件 → 申请按钮 `#applySQbtn`

- **先去 `/resume/certList` 看电子附件必填项**，避免填完才发现卡附件

## 必填坑

- **alert 风暴**：教育页院校 zTree 选择器会连续弹 alert 卡死页面自动化。每步脚本前覆盖 `window.alert` 和 `window.myalert`；卡死后开新页签，登录态保留。屏蔽后看不到校验提示，改为调用校验接口看 JSON
- **院校选择器只能选叶子**：海外院校选“海外院校”叶子后解锁手输校名；可用 zTree API 选中节点后写回隐藏字段再点“提交”
- 专业同样是叶子编码，找不到时选“其他”并必填补充说明字段
- 保存校验：院校编码长度需大于 5 位；排名必须 `N/M` 半角格式（如 `15/100`）
- select 的 option value 多为编码，按文本匹配后赋值 + change
- **工作经历结束时间不接受“至今”**，服务端直接报异常页；填最近月份并在内容里注明“进行中”
- 各页保存函数名不同（`save()`、`savehobby()`、`saveEdu()`），工作和家庭页走表单 submit
- 首选考试城市是省 → 市级联，城市可选范围有限
- 岗位页“申请”按钮滚出视口会点空
- 简历完整性接口 `checkResumeIntegrity` 返回 JSON：`FINISH1=0` 表示简历验证未过，`CERT=0` 表示附件缺，`QUALI=0` 资格证为选填不阻塞

## 附件限制

- **电子附件强制**：证件（身份证扫描件）、学生证或其他学生身份证明、成绩单
- 按 `intent.policies.attachments_required` 处理；材料放实例 `materials/`，命名见 `docs/materials.md`
- 个人信息页也有照片上传
