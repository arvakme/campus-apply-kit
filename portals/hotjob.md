# hotjob（大易 wecruit）

整理自该门户的实际使用（2026 年秋招季）。中国电信的 WinTalent 系统同属大易，见 `chinatelecom-wejob.md`。

## 识别方式

- 域名 `wecruit.hotjob.cn/SU<租户id>/`
- PC 校招列表 `/pb/school.html`，岗位详情 `/pb/posDetail.html?postId=...&postType=campus`
- 移动端候选人门户 `/mc/position/campus`（看板的投递链接有时给的是这个）
- 简历编辑 `resumeOperation.html?resumeId=...`，个人中心 `account.html#/account`，我的投递 `account.html#/myDeliver`

## 注册登录

- **仅微信扫码**：登录弹窗 `login-reg-modal` 里只有扫码，没有邮箱、手机号、账号密码入口。不要找邮箱入口，直接 handoff（kind=wechat_qr）
- 必须先勾“本人已阅读《企业隐私政策》”才会渲染二维码，勾好再截图

## 投递流程

列表行点击（真实鼠标）→ 新页签打开岗位详情 → “立即投递” → 若简历不完整弹“申请职位：要求中文简历完整度 100%” → “创建完整简历” → 上传简历文件弹窗（勾承诺 + 上传 PDF）→ 解析进入简历编辑页 → 补到完整度 100% → “保存” → 回岗位详情“立即投递” → “申请职位”弹窗：志愿（默认第 1 志愿）、内推码（可空）、选简历、勾承诺 → **“确认提交”**

## 必填坑

- **不认合成事件**：程序赋值 + input 事件不落库，保存仍报必填。文本框、textarea 一律真实点击聚焦 + 键盘输入；下拉真实点击展开再点选项
- **省市两级下拉**：选省后右侧第二列出现市列表，只选省会报“请选择XX市”，必须选到市
- 表单是 antd 单页长表单，左侧锚点导航，页面会“自动保存成功”，但最终以“保存”校验通过、完整度 100% 为准
- 专业库没有精确专业时，表单提示“需与留服认证一致，无则选其他”，选“其他国家/地区”类目项
- 金融类公司常有额外声明：从业资格考试、证监会系统从业经历、亲属证监会系统工作经历
- 家庭关系要填政治面貌等细项，按问题库
- “立即投递”按钮元素引用点击报被拦截时，按 role=button + 名称定位
- 下拉 `comboboxgrouping` 引用报不可见时，按元素中心坐标点击展开

## 附件限制

- 照片：维护者把 1.6MB 原图压到 800px 长边、约 80KB 上传成功
- “请上传最新简历附件”位：PDF
- 解析出的资格证书行，每行可能带额外必答选项

## 提交后核验

- 个人中心 `account.html#/account`：已投递职位数、最近投递
- 我的投递 `account.html#/myDeliver`：“投递成功”、第 N 志愿、城市、机构、简历名、投递时间
