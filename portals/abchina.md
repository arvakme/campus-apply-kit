# 中国农业银行（career.abchina.com.cn）

整理自该门户的实际使用（2026 年秋招季）。

## 识别方式

- 域名 `career.abchina.com.cn/build/index.html#/...`，农行自建门户，antd
- 岗位详情 `#/PositionDetails/:<id>`，简历 `#/MyResume`，登录 `LoginPage`，注册 `RegisterByPhone`
- 入口：官网报名 → 机构列表（总行各中心、分行）→ 机构公告 → 岗位列表

## 注册登录

- **注册只有手机号 + 短信验证码**，没有邮箱注册和扫码
- 登录：账号密码 + 字符图形验证码，或短信验证码 → 都要 handoff
- 预填手机号后 handoff，协议勾选留给用户
- 登录态检查：接管后 localStorage/cookie 里没有凭证、点“个人中心”跳登录页，说明用户只注册没登录，再 handoff 一次

## 投递流程

机构公告确认资格（届数、截止、每人限投岗位数、四六级分数线）→ 岗位列表选岗 → 岗位详情“申请岗位” → 先完善简历（左栏 12 个区块，全部打勾）→ 回岗位详情“申请岗位” → 申请对话框：考试类别、考试地点 → **“确认申请”**

- 对话框状态不跨页保持，每次都要重选考试类别和地点

## 必填坑

- 12 个区块：基本信息、教育背景、外语能力、奖励情况、亲属关系、学生干部、工作经历、社会实践、技能及证书、自我评价、其他（声明）、发表文章（非必填）
- 基本信息含：身高、户口（到县）、入党时间、备用联系人、服从调剂、当前状态、建档立卡、服役、证件照、生活照
- **基本信息弹层“取消”会丢弃整张表**，只有“保存”落库；校验不过（如生活照缺失）时表单只在内存
- **Escape 会关掉整个弹窗丢数据**，不要用
- antd select 选项鼠标点击常不落库 → 对 `li` 派发 mousedown 再 click；radio 点 wrapper
- antd Cascader：叶子项先滚动到居中再点，就近滚动可能滚不到位导致点空关菜单；选中后弹层不自动关，会盖住下一行，确认值落上后再操作；残留弹层可以隐藏，不要删 DOM
- 弹层里的按钮超出视口时先滚动，滚动容器是 form-item 本身
- 专业库没有精确专业时选“其他专业”手输
- 父母出生日期若无数据，门户默认值会留着，终审时提醒用户

## 附件限制

- 上传按钮先打开裁剪器，裁剪器里的“选择照片”才触发文件选择
- 证件照、生活照都必填

## 提交后核验

- 岗位详情按钮变“已申请”
- 个人中心 → 我的投递：第 N 志愿、岗位、申请时间、考试地点
- 科技类岗位有统一笔试，时间另行通知
