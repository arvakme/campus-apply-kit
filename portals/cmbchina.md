# 招商银行（career.cmbchina.com）

整理自该门户的实际使用（2026 年秋招季）。

## 识别方式

- 域名 `career.cmbchina.com`，招行自有门户，React + antd
- 岗位详情 `/positionDetail/school?publishId=...`，简历 `/center/resume`，应聘历史 `/center/history`
- 职位列表数量大（数百岗），同集团子公司（如招银网络科技）另有独立门户，按雇主主体防重

## 注册登录

- 邮箱 + 6 位验证码，**发码前有滑块拼图** → handoff（kind=captcha）
- 验证码有效期约 2 分钟，worker 取码往返常超时 → 让用户手输
- **证件号与手机号绑定**：保存简历时若提示证件号已绑定其他手机账户，需要用该手机号登录或致电客服解绑，交用户决定
- 登出：用户中心菜单依赖 CSS hover，脚本环境下可能展不开

## 投递流程

- **新账号**：职位详情“立即投递” → 空白申请表（解析简历 → 个人信息 → 教育 → 家庭 → 技能 → 实践 → 荣誉 → 社团）→ 保存
- **老账号（已有档案）**：“个人简历”逐节编辑，各节独立“保存”，档案即简历，没有解析步骤
- 两者最后都是：职位详情“立即投递” → **“投递确认”预览弹窗** → **“确定并投递”**
- 登录后先看应聘历史，老账号的旧档案要逐字段按问题库覆盖

## 必填坑

- **保存后服务端才暴露的必填**：身高、专业名称、毕业设计（本科、硕士各一）、实践单位联系人和电话、生活照、社团结束时间
- 实践职责限 30 字且禁特殊字符
- **专业名称是专业库 combobox**，库里没有精确专业时按问题库的专业映射规则选，值显示在 `.ant-select-selection-item`，编码存在隐藏 input
- 家庭节有“近亲属”问题 + 紧急联络人/父/母三张卡
- 编辑节按钮 class `.btn-add-zero`，节内添加 `.btn-add`，删除卡 `.btn-remove` + popover 确认（不是 modal）
- 新增卡片会克隆上一条的数据，需要清空重填
- 查看态分节懒渲染，`innerText` 读不全，用 `textContent`
- 期望城市是虚拟列表：滚动 `rc-virtual-list-holder` 到目标项再点
- antd select 打开：对 `.ant-select-selector` 派发 mousedown + mouseup + click
- cascader（生源地/出生地）同样派发三联事件展开二级
- RangePicker 第二格可以键盘直接输入 `YYYY-MM-DD` + 回车
- 日期面板定位异常时先滚动让字段居中
- 承诺协议 checkbox 必须真实鼠标点击，且元素在视口内
- 解析出的实践经历可能重复，要删掉多余的

## 附件限制

- 证件照：实测压到约 14KB 通过（长边约 500px）；上传后显示“替换照片”
- 生活照：必填，约 100KB 原图可直接传
- 简历 PDF：只在新账号申请表的“解析简历”步上传，档案页没有附件区

## 提交后核验

- `/center/history` 应聘历史：岗位、投递时间、“已投递”、“简历筛选-进行中”、“简历已锁”
