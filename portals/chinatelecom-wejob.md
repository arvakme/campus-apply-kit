# 中国电信集团统一校招（wejob，WinTalent/大易）

整理自该门户的实际使用（2026 年秋招季）。

## 识别方式

- 域名 `wejob.chinatelecom.com.cn`
- 简历编辑页 `#/er/<hash>`（新页签打开）
- WinTalent 老 AngularJS 系统，字段是原生 input/select

## 注册登录

- **仅手机号 + 图形验证码 + 短信验证码**（短信登录 / 去注册），没有邮箱或密码入口 → handoff
- 注册成功后要手动关“请前往登录”弹窗
- 登录态标识：右上角 `PC_xxxxx` 头像

## 投递流程

岗位页“立即投递” → “投递简历”弹窗：无简历 → “去创建”；有简历未完善 → “去完善” → 附件上传解析或在线填写 → 补齐 → “暂存并退出” → 回岗位页“立即投递” → 投递确认

## 必填坑

- 原生控件：radio 直接 click 有效；select 设 value 后派发 change；文本用原生 setter + input/change
- **省市两级联动**：选省后市级选项异步加载，需要等待；海外院校省级选“海外”，市级自动“海外”
- 填证件号后系统自动校验出生日期，弹“与生日不符，立即更新”，确认即可
- **浮动底栏有“取消 / 暂存并退出 / 保存”**：“暂存并退出”是草稿；“保存”可能等于提交，不确定时不点
- 教育卡日期格式 `YYYY/MM/DD`
- 家庭卡关系选项是“父子/母子”这类写法，另有“是否在电信任职”

## 附件限制

- **个人照片上限 1MB**，实测压到约 58KB 通过；上传成功后 file input 从 DOM 消失，单元格显示“文件名 删除”
- 附件 input 顺序：个人照片 → 学籍验证 → 成绩单 → 外语证明 → 身份证 → 简历 → 其他
- 学籍在线验证报告、成绩单、外语成绩证明、身份证正反面**可能为强制附件**，按 `intent.policies.attachments_required` 处理

## 提交后核验

- 门户“我的志愿”查看投递记录（尚未走到提交，待补）
